# Create Weekly Status Report

- Output format: Markdown.
- Use exactly these sections in this order: Accomplishments, Blockers, Next Week.
- Write each section as a bullet list.
- Use bullet points only; no numbered lists, tables, or paragraphs.
- Keep the report concise and professional.
- Max length: 20 lines total.
- No fluff words, marketing language, or filler.
- Focus on facts, risks, decisions, and delivery impact.
- Use clear, short statements with concrete outcomes.
- Mention blockers only when they affect delivery or quality.
- For next week, list only the most important planned actions.
- Keep tone formal and direct.
- Do not include headings beyond the required three sections.
- Ensure the output is suitable for stakeholder review.
