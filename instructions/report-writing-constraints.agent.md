# Shared Report Writing Constraints

- Follow all shared report-writing rules before finalizing any stakeholder-facing output.
- Use Markdown only.
- Use bullet points only; no numbered lists, tables, or paragraphs.
- Keep the tone professional, direct, and factual.
- Keep content concise and suitable for stakeholder review.
- Remove fluff, filler, marketing language, and vague statements.
- Focus on delivery impact, risks, decisions, and next actions.
- Use short, specific statements with concrete outcomes where available.
- Do not invent numbers, dates, or commitments.
- Do not include raw credentials, secrets, or private data.
- If a value is unavailable, label it clearly instead of guessing.
- Keep output under the required maximum line count for the workflow using it.
- Ensure the final output is reviewable without extra interpretation.
